# 智能助手 原型规格

> 本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

## 当前方案

- 原型意图：为建材/水泥行业数字化管理平台提供嵌入式 AI 智能助手，以悬浮对话框形式叠加在业务页面上，用户无需跳转即可获得状态监测、故障诊断、运行报告、统计报表等智能分析服务。
- 使用场景：日常运维人员通过右下角入口唤起助手，选择快捷功能或手动输入问题，助手返回专业分析结果；同时可管理历史对话任务。
- 当前表达：对话框 + 历史任务侧边栏的完整交互原型，含浮动图标唤起、对话框放大/缩小、快捷卡片预设文案、附件上传、深度思考开关等功能。

## 事实与输入

### 用户确认事实

- 主色调：紫罗兰紫 `#7C3AED`
- 机器人图标：用户提供自定义图标 `src/prototypes/smart-assistant/assets/robot-icon.png`
- 对话框原始尺寸：宽度 2/3 视口、高度 1/4 视口（最小高度 280px）
- 侧边栏默认收起
- 侧边栏不包含"技能"和"即时通讯"入口
- 输入框为 textarea，自动撑高，最多显示 3 行，超出后出现滚动条
- 附件上传图标位于输入框右侧（深度思考开关左侧）
- 搜索任务在任务列表上方单独占一行

## 原型范围

### 本次呈现

- 右下角浮动图标（hover 放大 + 阴影加深）
- 对话框（原始尺寸 + 全屏两种模式）
- 对话框顶部标题栏（侧边栏折叠按钮、关闭按钮、标题、全屏切换）
- 历史任务侧边栏（收起/展开动画、新建任务、搜索任务、按时间分组的任务列表、任务状态标签、hover 显示更多操作菜单）
- AI 欢迎消息气泡
- 4 张快捷功能卡片（状态监测/故障诊断/运行报告/统计报表，点击选中 + 预设文案填入输入框）
- 底部输入栏（textarea 自适应高度、附件上传/粘贴/回显/删除、深度思考开关、发送按钮）

### 本次不呈现

- AI 实时对话流式输出
- 任务数据持久化与后端交互
- 深度思考的实际推理逻辑
- 语音输入
